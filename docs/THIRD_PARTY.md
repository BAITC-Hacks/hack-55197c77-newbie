## Вклад AI и участника

Участник выбрал задачу, задавал требования к карте, взаимодействию с районами,
объяснениям последствий и подключению настоящего AI; проверял пользовательский
результат и выполнял отправку коммитов. Codex существенно участвовал в реализации,
тестировании и подготовке документации. Работа не представляется как полностью
написанная человеком без помощи AI.

Runtime-модель получает только синтетический датасет, решения и готовые результаты
расчёта. Её реакция на сценарий — новый запрос к API по кнопке. Авторские
пояснения из `data/measure_explanations.json` составлены при разработке с помощью
AI и служат отдельным разбором по правилам; они не выдаются за опрос жителей.

## Собственные материалы проекта

Python-модули, HTML/CSS/JavaScript, SVG-схема, тесты и пояснения разработаны
в рамках этой работы с помощью Codex. SVG не использует внешние картографические
тайлы или географические границы. Сторонние UI-шаблоны, шрифтовые файлы и изображения
в текущей версии не подключены. Внешние Python/npm-пакеты не требуются.

Установка Git, Python и других инструментов и учебная работа с Git до старта
использовались как подготовка среды. Конкретная история кода решения отражена
в коммитах рабочего репозитория; организационные обстоятельства подтверждает участник.

Этот файл раскрывает происхождение компонентов и не назначает новую лицензию
на материалы организаторов, модель OpenAI или весь проект.
