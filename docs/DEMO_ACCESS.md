# AI-доступ для локальной проверки

Выбранный способ сдачи — запуск на компьютере эксперта по [README](../README.md).
Публичное размещение не используется. Действующий API-ключ и параметры подключения
передаются в `.env.example` приватного репозитория команды.

## Получение доступа

Эксперт получает актуальную версию приватного репозитория или его закрытый архив.
В `.env.example` уже заполнены `AI_API_KEY`, `AI_MODEL`, `AI_BASE_URL` и
`AI_OUTPUT_FORMAT`. Вручную искать ключ или регистрировать платный аккаунт OpenAI
не требуется. Для запуска файл копируется в `.env` рядом с `web_server.py`.

`.env.example` в этой сдаче — готовая конфигурация с действующим ключом.
Она предназначена для лиц, имеющих доступ к закрытому репозиторию, и не должна
переноситься в публичные материалы. Ключ доступен получателям файла; пароль
и вход в личный кабинет участника для проверки приложения не требуются.

Команда обеспечивает доступный лимит во время проверки 24–28 сентября и,
при выходе в финал, Demo Day 29 сентября. Соответствие способа проверки
п. 5.6.6 Положения и результат проверки определяет Организатор.

## Действия проверяющего

1. Получить актуальный код и выполнить подготовку окружения по README.
2. Скопировать `.env.example` в `.env` в корне проекта:

   Windows / PowerShell:

   ```powershell
   if (!(Test-Path .env)) { Copy-Item .env.example .env }
   ```

   Linux / macOS:

   ```bash
   test -e .env || cp .env.example .env
   ```

   Существующий `.env` не перезаписывается: если он уже есть, проверить в нём
   актуальность настроек. Python читает именно `.env`; файл `.env.example`
   автоматически не подхватывается. Дополнительного расширения `.txt` быть не должно.
3. Запустить `web_server.py` интерпретатором из созданного окружения, как показано
   в README. Открыть `http://127.0.0.1:8000`.
4. Нажать «Загрузить пример» → «Рассчитать сценарий».
   Ожидаются Score 56,54307 (на экране 56,54), остаток бюджета 5 и 0 критических значений.
5. Нажать «Получить AI-анализ». Успех — надпись «Ответ AI получен» с моделью
   и временем, общий вывод и объяснения всех пяти мер и направлений.
6. Изменить район M7 с Нуры на Есиль, заново рассчитать и запросить AI:
   Score 55,29777 (на экране 55,30), один критический показатель, новый разбор.
7. После проверки остановить сервер сочетанием Ctrl+C.

Ключ используется Python-сервером для обращения к AI-провайдеру и не передаётся
в интерфейс симулятора. Файлы `.env` и `.env.example` не раздаются веб-сервером.
