# Аким на 5 часов

Презентация проекта на русском языке, 7 слайдов в формате 16:9.

- [Редактируемая презентация PPTX](akim-na-5-chasov.pptx)
- [Презентация PDF для просмотра](akim-na-5-chasov.pdf)

В PPTX редактируются текст и таблица сравнения. Карта и знак взяты из интерфейса проекта. PDF сохраняет внешний вид слайдов; для изменений используйте PPTX. Источники и подсказки спикеру также находятся в заметках слайдов.

## Сценарий демонстрации

Установка и доступ к AI описаны в [основном README](../README.md). После запуска откройте `http://127.0.0.1:8000`.

1. Нажмите «Загрузить пример», затем «Рассчитать сценарий». Покажите Score 56,54, остаток бюджета 5, критических показателей 0.
2. Сохраните этот результат как A.
3. Для M7 «Школа + детсад» смените район с Нуры на Есиль. Другие меры оставьте прежними.
4. Рассчитайте текущий вариант B и сравните его с сохранённым A. Покажите Score 55,30, прежние расходы 95 и один критический показатель.
5. Получите AI-анализ для текущего сценария. Дождитесь подтверждения получения ответа.
6. Скачайте отчёт. Он содержит выбранные решения, расчёт, пояснения по правилам и уже полученный AI-анализ.

AI требует интернет и настройки API из инструкции проекта. Числовая модель и пояснения по правилам работают локально. В этом браузере сохраняется вариант A; несохранённый B сбрасывается при обновлении страницы.

## Источники и ограничения

Числа взяты из `data/city.json` и расчёта `simulator.py`. В примере A используются M7, M8 и M10 в Нуре, M12 по городу, M5 в Сарыарке. В B отличается только район M7. Разница Score составляет 1,24530 балла. Преимущество A относится к этому сравнению, поиск глобального оптимума не реализован.

- [ТЗ организаторов](https://docs.google.com/document/d/1oDZtYnBgbcn_Ii7vleP87hkARJ2HmbXl7Cw_rsCxqpo/edit)
- [Датасет и правила](https://docs.google.com/document/d/1Uc-GdGoKhDY-spu8V50-ZMm33t2CjYLP/edit)
- [Раскрытие сторонних компонентов и использования AI](../docs/THIRD_PARTY.md)

Данные синтетические, карта обобщена. Реальный прогноз требует отдельной проверки. Используется трактовка подробного датасета: пять мер могут охватывать не все направления, не более двух мер одного направления. Эту трактовку следует подтвердить у организаторов. Случайные события и публичное серверное размещение не входят в текущую версию.
